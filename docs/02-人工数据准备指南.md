# 人工数据准备指南

## 1. 本阶段人工需要准备什么

先准备少量开发样本，系统跑通后再扩大规模：

1. 5 名组内或熟悉的同学；
2. 每人回答 3 道固定题；
3. 每题录制 60–120 秒；
4. 共得到约 15 条开发音频；
5. 至少包含一条流畅、一条停顿明显、一条语气词较多的回答。

系统稳定后扩展到 20–30 人、60–90 条音频。

## 2. 建议先录的三道题

1. 请用 1 分钟进行自我介绍，并说明你应聘软件开发岗位的优势。
2. 请介绍一个你参与过的项目，并说明你负责的部分。
3. 请描述一次你遇到技术难题并最终解决的经历。

## 3. 录音规范

- 建议使用 Chrome 或 Edge，以及电脑或手机自带麦克风；
- 主体样本在安静室内录制；
- 额外保留 2–3 条轻微噪声样本测试鲁棒性；
- 每段开头和结尾保留约 1 秒安静；
- 只允许一人说话；
- 不念真实姓名、手机号、学号等隐私信息；
- 文件名使用匿名编号，例如 U012_dev_Q03_01.wav；
- 是否允许答辩播放，需要单独记录。

## 4. 目录放置

真实数据放在以下本地目录，目录已被 Git 忽略：

~~~text
data/raw_audio/
data/processed_audio/
data/annotations/private/
data/demo_samples/private/
~~~

不要把真实录音放进 data/templates 或 data/question_bank。

## 5. 人工标注步骤

### 内容与流畅度评分

1. 两名标注者分别听同一段音频；
2. 不查看对方分数；
3. 按模板填写内容分和流畅度分；
4. 分差较大时讨论原因；
5. 保存原始两份分数和最终共识分。

### 停顿标注

1. 用播放器记录明显停顿的开始和结束秒数；
2. 标记句间、句内或无效噪声；
3. 记录前后文字；
4. 对 500 毫秒附近的边界样本保留备注；
5. 不把录音开头、结尾的静音算作表达卡顿。

## 6. 使用同意

录音前让参与者阅读并确认 data/templates/录音使用同意书模板.md。参与者可选择：

- 仅用于系统开发；
- 可用于匿名指标统计；
- 可在课堂答辩中播放；
- 是否允许保留到课程结束后。

如果未明确允许答辩播放，只能展示匿名统计或转写文本。

## 7. 暂时不需要准备

- 不需要下载 AISHELL-1 全量数据；
- 不需要下载 WenetSpeech；
- 不需要人工制作几百小时语音；
- 不需要训练 ASR 模型；
- 不需要拍摄面部视频；
- 不需要提前购买大模型 API。
