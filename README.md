# AI 面试训练与表达分析系统

> 工程实训项目：面向大学生求职场景的中文模拟面试训练与表达反馈系统。

## 项目背景

大学生在准备技术岗位面试时，通常只能通过反复录音或同伴评价进行练习，难以直观看到回答是否切题、结构是否完整，以及语速、停顿和语气词等表达问题。

本项目作为工程实训作品，设计并实现了一套从网页录音、中文语音转写到可解释反馈的完整系统。用户回答面试题后，系统从“内容质量”和“表达流畅度”两个方面生成训练报告，并保留多次练习记录，帮助用户根据证据持续改进表达。

系统定位是个人训练辅助工具，不预测候选人是否会被录用，也不对外貌、性别、年龄、方言或口音进行评价。

## 功能简介

- **岗位题库**：当前提供软件开发岗位 15 道题，支持按项目经历、技术基础、工程实践等类别筛选。
- **网页录音与音频上传**：可直接调用浏览器麦克风录音、试听、重新录制，也可上传 WAV、WebM、MP3、M4A、OGG 或 FLAC。
- **本地中文转写**：使用 FunASR 和本地预训练模型完成中文语音识别、语音活动检测、标点恢复与字词时间戳提取。
- **表达分析**：计算有效语速、明显停顿、长停顿、停顿占比、回答时长和语气词数量。
- **内容分析**：检测题目要点、STAR/逻辑结构、个人职责、具体行动、项目结果和量化事实。
- **可解释报告**：展示内容分、表达分、分项依据、证据句、四维雷达图、停顿时间轴和优先改进建议。
- **转写修正**：保留模型原始转写，允许用户修正识别错误并重新生成内容报告。
- **训练历史**：在本机保存历史报告，并展示同一道题最近多次练习的分数趋势。

## 技术流程

```text
网页录音或上传音频
  → 文件格式、大小与时长校验
  → FFmpeg 转换为 16 kHz 单声道 WAV
  → FSMN-VAD 语音活动检测
  → Paraformer 中文转写与字词时间戳
  → CT-Punc 标点恢复
  → 语速、停顿、语气词等语音指标计算
  → 题目要点、STAR 和事实证据规则分析
  → SQLite 保存报告
  → Vue 页面展示结果与历史趋势
```

## 技术栈

- 前端：Vue 3、Vite、ECharts、MediaRecorder API
- 后端：Python 3.12、FastAPI、SQLAlchemy、SQLite
- 语音处理：FFmpeg、FunASR、PyTorch、ModelScope
- 预训练模型：Paraformer、FSMN-VAD、CT-Punc
- 测试：pytest、HTTPX

本项目没有从零训练或微调语音模型。预训练模型用于离线推理；自建匿名录音和人工标注主要用于计算字符错误率、停顿检测指标及规则评分误差，并据此改进面试场景中的分析规则。

## 本地运行

项目当前按 Windows 本地单机环境实现。准备好项目专用 Python 环境、前端依赖、FFmpeg 和本地模型后，分别启动：

```powershell
.\scripts\dev-backend.ps1
```

```powershell
.\scripts\dev-frontend.ps1
```

浏览器访问：

- 前端：<http://localhost:5173>
- 后端接口文档：<http://127.0.0.1:8000/docs>

运行自动测试和前端构建检查：

```powershell
.\scripts\run-tests.ps1
```

## 数据与隐私

- 原始录音、人工标注、模型文件、数据库和运行缓存只保存在本机，不提交到公开仓库；
- 音频文件使用随机编号保存，不要求使用真实姓名；
- 当前分析流程不调用云端大语言模型；
- 页面分数是用于个人练习的可解释规则基线，不构成招聘或录用判断。

## 当前范围

当前版本以工程实训演示和小规模真实数据验证为目标，主要限制包括岗位较少、CPU 首次加载模型较慢、样本量较小，以及停顿和内容评分规则仍需通过独立测试集继续验证。
